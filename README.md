# GamePackBuilder

Утилита для каталогизации ретро-игр и сборки игровых паков.

## Возможности

- Сканирование коллекции игр и формирование каталога по системам
- Просмотр списка систем и игр, редактирование карточек
- Сборка игровых паков для портативных консолей
- Загрузка метаданных и медиа через ScreenScraper

## Статус

В разработке.
